A modern, feature-rich habit tracking application built with Next.js, TypeScript, and Tailwind CSS. Track your daily routines, visualize progress, and build lasting habits with beautiful data visualizations.

## Features

- 🎯 **Track Multiple Habits** - Monitor sleep, water intake, exercise, and more
- 📊 **Interactive Charts** - Weekly and monthly progress visualization with Recharts
- 🔥 **Streak Tracking** - Maintain motivation with daily streak counters
- 🎨 **Modern UI** - Clean, responsive interface with Framer Motion animations
- 📱 **Mobile-Friendly** - Works perfectly on all device sizes
- 💾 **Local Storage** - Data persists between sessions
- 🚀 **Instant Feedback** - Notifications for streak milestones

## Technologies Used

- ⚛️ Next.js 14 (App Router)
- 💅 Tailwind CSS
- 📜 TypeScript
- 🎞️ Framer Motion (animations)
- 📈 Recharts (data visualization)
- 🧠 Local Storage (data persistence)
